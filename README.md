# Azor: Urmărirea prin oraș

Joc 3D endless runner cu suport WebXR AR, detectarea podelei și modele glTF animate.

## Joacă

Deschide [`prinde_sfera_ar.html`](./prinde_sfera_ar.html) sau publică GitHub Pages și accesează `https://floareapitu10-source.github.io/JOC-azor-urmarirea-prin-oras/prinde_sfera_ar.html`.

## Cerințe

- Browser compatibil WebXR `immersive-ar` și `hit-test` pentru modul AR.
- HTTPS și telefon compatibil pentru camera AR și controlul prin înclinare.
- Dacă AR nu este disponibil, jocul 3D funcționează în browser.

Instrucțiunile complete sunt în [`instructiuni.html`](./instructiuni.html). Modelele locale sunt în `models/`.
